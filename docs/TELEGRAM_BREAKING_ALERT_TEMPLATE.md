# TELEGRAM BREAKING ALERT TEMPLATE

본 문서는 텔레그램 속보 카드 형식을 코드보다 먼저 박제한다.
구현 코드가 본 문서를 끌고 가지 않는다. 본 문서가 구현을 끌고 간다.

---

## 1. 목적

- 텔레그램 카드 형식이 매번 흔들리면 운영자는 매번 다른 카드를 읽게 된다. 이는 운영 신뢰를 깬다.
- `docs/BREAKING_ALERT_FILTER_SPEC.md` 가 **무엇을 보낼지**(분류 기준)를 정한다면, 본 문서는
  **어떤 모양으로 보낼지**(카드 형식)를 정한다. 둘은 한 묶음이다.
- 카드 문구도 코드보다 먼저 기준 문서로 박는다. 텔레그램 send 함수가 형식을 자체 결정하지 않는다.
- 본 문서가 박제되어야 그 다음 단계(점수식 / dedup 데이터 모델 / 발송 큐) 가 같은 가정 위에서 작성된다.

---

## 2. 카드 종류

본 시스템의 텔레그램 카드는 **2종**으로만 구분한다. 그 외 형식 금지.

- **BREAKING_NOW 즉시 알림 카드** : 분류 즉시 1건씩 발송.
- **05:00 Top5 브리핑 카드** : KST 05:00 정각 1회, 야간 큐 상위 5건을 1카드로 묶음.

### 차이 1표

| 항목 | BREAKING_NOW | 05:00 Top5 |
|---|---|---|
| 발송 시점 | 분류 즉시 (시간 무관) | KST 05:00 정각 1회 |
| 묶음 단위 | 1건 = 1카드 | 5건 = 1카드 |
| 길이 한도 | 600자 권장 | 800자 권장 |
| 필드 수 | 8필드 풀카드 | 항목당 2줄 압축 |
| 긴급도 표기 | high / medium | 없음 (이미 후순위) |
| 운영자 액션 힌트 | 포함 | 미포함 |
| 분류 사유 노출 | 1줄 명시 | 미노출 (Top5 진입 자체가 사유) |
| 원문 링크 위치 | 카드 본문 하단 | 카드 끝 5개 묶음 1블록 |

---

## 3. BREAKING_NOW 카드 고정 구조

8필드. **순서 변경 금지. 누락 금지. 추가 금지.**

1. **제목** — 원문 그대로. 낚시 제목이면 앞에 `▲` prefix.
2. **핵심 요지** — 1~2 문장. 무엇이 일어났는지만.
3. **관련 키워드** — 매칭된 강한 키워드 최대 3개. 슬래시(`/`) 구분.
4. **영향 자산군** — 금융 / 투자 / 크립토 / 주식 중 매칭 영역. 복수 가능.
5. **긴급도** — `high` 또는 `medium`. (low 는 BREAKING_NOW 자체가 아님.)
6. **속보 분류 사유** — 1줄. "이 기사가 왜 BREAKING_NOW 인지" 한 문장.
7. **원문 링크** — URL 1개. 단축 URL 금지.
8. **운영자 액션 힌트** — 1줄. `즉시 확인` / `정보만` / `추가 검증 필요` 중 1개 + 짧은 보충.

부가 정보(2개, 본 8필드와 별도 영역에 표기) :

- **수집 시각** — `YYYY-MM-DD HH:MM KST`
- **카드 종류 prefix** — 본문 첫 줄은 항상 `[속보]` 로 시작.

---

## 4. BREAKING_NOW 카드 문장 규칙

- **한국어 only.** 번역체 금지. 영어 단어 단독 사용 금지(고유명사 / 티커 제외).
- **단정적 투자 조언 금지.** 매수 / 매도 / 추천 / "지금 들어가야" 류 표현 금지.
- **1카드 1이슈.** 한 카드에 두 사건 묶지 않는다.
- **자극적 표현 금지.** "충격", "공포", "패닉", "대박" 단독 사용 금지. 본문 사실로 대체.
- **"왜 지금 봐야 하는지" 가 분류 사유 1줄에 명시되어야 한다.** 시점성이 카드의 핵심이다.
- **길이 제한** :
  - 카드 전체 600자 이하 권장 (텔레그램 1메시지 잘림 방지).
  - 제목 60자 이하.
  - 핵심 요지 2문장 이하.
  - 분류 사유 1문장.
  - 운영자 액션 힌트 1문장.
- **수치 표기** : 단위 명시 필수. 비교 기준 시점 명시. 출처 본문에 있는 형태 그대로.
- **이모지 금지.** 시각적 강조는 `▲` (낚시 제목 prefix) 1개만 허용.

## 7. 05:00 Top5 브리핑 카드 구조

### 7.1 카드 헤더

- **제목** : `[새벽 5시 브리핑] {{date}} — Top 5`
- **시간 범위** : `{{start_kst}} ~ {{end_kst}}` (보통 전일 22:00 ~ 당일 05:00)
- **선정 기준 1줄** : `야간 CANDIDATE 점수 상위 5건. BREAKING_NOW 발송분 제외.`

### 7.2 항목 형식 (5건 반복)

각 항목은 **정확히 2줄**.

```
{{rank}}. [{{asset_group}}] {{title_short}}
   {{one_line_summary}}
```

- `rank` : 1 ~ 5
- `asset_group` : 금융 / 투자 / 크립토 / 주식 중 1개. 복수면 슬래시 구분.
- `title_short` : 50자 이하. 원문 제목을 압축. 낚시는 ▲ 표시 안 함(이미 야간 큐 통과 건).
- `one_line_summary` : 70자 이하. 시장 / 자산군 중심으로 압축.

### 7.3 카드 푸터

- 1줄 안내 : `BREAKING_NOW 로 이미 발송된 건은 본 Top5 에서 제외됨.`
- **원문 링크는 항목 옆에 붙이지 않는다.** 카드 끝에 5개 URL 묶음 1블록으로만 제공.

### 7.4 BREAKING_NOW 제외 원칙

- 야간 큐(전일 22:00 ~ 당일 05:00) 에 적재된 CANDIDATE 만 후보가 된다.
- 같은 시간 범위에서 BREAKING_NOW 로 이미 발송된 건은 **항상 제외**. 중복 노출 금지.
- 5건이 안 채워지면 채워지는 만큼만 발송. 더미 항목 금지.

## 8. 05:00 Top5 카드 문장 규칙

- **압축형 only.** 형용사 / 부사 최소화. 문장 끝 마침표는 생략 가능.
- **중복 표현 금지.** 5건 중 같은 키워드 / 자산군이 3건 이상이면 표현을 의도적으로 다르게 한다.
- **한 항목당 정확히 2줄** (rank 줄 + 요약 줄). 1줄도 3줄도 금지.
- **시장 / 자산군 중심으로 요약.** 인물 / 정치 공방 / 추측 표현 금지.
- **카드 전체 길이 800자 이하 권장.**
- **이모지 금지.** 카드 헤더에 1개도 안 붙인다.

## 10. 예외 규칙

### 10.1 중복 이슈

- 직전 60분 윈도우 내 동일 이슈가 BREAKING_NOW 로 이미 발송됐다면 재발송 금지 (`BREAKING_ALERT_FILTER_SPEC §7.2` 동일 정책).
- 후속 업데이트가 새로운 §4 충족 조건을 추가로 만족할 때만 새 카드 발송 (예 : 거래소 출금 정지 → 6시간 후 재개 발표).
- Top5 는 BREAKING_NOW 로 이미 발송된 건을 항상 제외.

### 10.2 링크 없음 / 본문 짧음

- 원문 링크 미식별 → BREAKING_NOW 카드 발송 보류, HOLD 처리.
- 본문 3 문장 미만 → 같은 처리.
- Top5 항목도 원문 링크가 없으면 그 항목은 자동 탈락. 다음 순위가 승격.

### 10.3 긴급도 애매

- high / medium 판정이 갈리면 **한 단계 강등** (high → medium).
- medium 도 애매하면 BREAKING_NOW 자체에서 빠지고 CANDIDATE 강등.
- 애매하면 보내지 않는다. 보수가 기본값이다.

### 10.4 주말 / 공휴일

- 한국 시장 관련 BREAKING_NOW 는 긴급도 한 단계 강등 (시장 미개장 사유).
- 단 거래소 사고 / 해킹 / 정책 발표는 평일과 동일 긴급도 유지.
- Top5 브리핑은 주말 / 공휴일에도 정상 발송 (시장이 닫혀도 정보는 누적된다).

## 11. 운영 메모

- 본 문서는 **텔레그램 카드 형식 기준선**이다. 구현 코드가 본 문서를 끌고 가지 않는다.
- 본 문서와 `docs/BREAKING_ALERT_FILTER_SPEC.md` 가 충돌하면 **FILTER_SPEC 우선**.
  본 문서는 형식만 정한다. 분류 / 게이트 / 임계값은 FILTER_SPEC 가 위에 있다.
- 본 문서와 `docs/ACCOUNT_CONSTITUTION.md` 가 충돌하면 **ACCOUNT_CONSTITUTION 우선**.
  계정 정체성과 금지 표현이 카드 양식보다 위에 있다.
- 카드 8필드 / 5건 묶음 / 600자·800자 길이 임계는 운영 중 조정될 수 있으나,
  조정 시 **반드시 본 문서를 먼저 수정**하고 그 뒤 구현 / 알림 로직을 바꾼다.
  코드가 본 문서보다 앞서 바뀌면 본 문서의 의미가 사라진다.
- 자극적 표현이 누적되면 운영 신뢰가 무너진다. 형식은 보수가 기본값이다.
- 본 문서의 다음 단계 후속 문서 (별 세션) :
  - 야간 Top5 점수식 스펙
  - 텔레그램 발송 dedup 데이터 모델 스펙
  - BREAKING_NOW 후 24h 후속 보도 자동 트래킹 스펙
