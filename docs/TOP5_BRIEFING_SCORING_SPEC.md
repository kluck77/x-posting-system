# TOP5 BRIEFING SCORING SPEC

## 1. 목적

- 22:00 ~ 05:00 KST 사이에 쌓인 CANDIDATE 기사 중에서 05:00 KST Top5 브리핑에 올릴 5건을 정하는 점수 기준이다.
- 본 문서는 다음 두 문서와 한 세트다.
  - `docs/BREAKING_ALERT_FILTER_SPEC.md` : "무엇이 알림 후보냐"를 정한다 (라벨링).
  - `docs/TELEGRAM_BREAKING_ALERT_TEMPLATE.md` : "어떤 형식으로 보내냐"를 정한다 (카드 양식).
  - 본 문서 : "그 후보들 중 정확히 어떤 5건을 고르냐"를 정한다 (선정 점수).
- 점수식을 코드보다 먼저 문서로 고정하는 이유
  - 임계값과 가중치가 코드에만 박혀 있으면 다음 세션이 다시 추정한다.
  - 점수식은 운영자 판단의 영역이지 구현 디테일이 아니다.
  - 본 문서만 갱신하면 다음 채택 결과를 손으로도 시뮬레이션할 수 있어야 한다.
  - 코드 변경 없이 가중치 / 패널티 조정이 가능해야 한다.

## 2. 적용 범위

- **시간대** : 22:00 ~ 05:00 KST 수집분 한정.
- **라벨** : `CANDIDATE` 만 본다.
- **제외 라벨**
  - `BREAKING_NOW` : 즉시 발송 라인. 본 점수식의 대상이 아니다.
  - `HOLD` : 평가 대상에서 제외.
  - `REJECT` : 평가 대상에서 제외.
- **용도** : 05:00 Top5 브리핑 선정에만 쓴다.
- **비대상** : 일반 큐 / 일반 평가 / 낮 시간대 발행 결정에는 직접 적용하지 않는다.
- 본 문서가 책임지는 범위는 "점수 산정 + 5건 선정 로직" 까지이며, 카드 텍스트 형식은 `TELEGRAM_BREAKING_ALERT_TEMPLATE.md` 가 책임진다.

## 3. 기본 원칙

- 많이 모은 기사가 아니라 발행 가치가 높은 기사 상위 5개를 뽑는다.
- 신선도 / 시장 영향 / 근거 강도 / 계정 적합도 4축을 우선으로 본다.
- 애매하면 점수를 낮게 준다 (낙관 편향 금지).
- 동률이면 더 보수적인 쪽을 우선한다.
- "5개를 채우는 것"보다 "기준을 지키는 것"이 우선이다.
- 점수는 운영자가 손으로도 채점 가능한 수준이어야 한다. 정밀한 척하는 가짜 소수점 금지.

## 4. 점수 구조

- 총점 100점 만점.
- 가점 4축 + 패널티 3축으로 구성한다.

| 축 | 종류 | 배점 |
|---|---|---|
| 신선도 | 가점 | 20 |
| 시장 영향도 | 가점 | 30 |
| 근거 강도 | 가점 | 25 |
| 계정 적합도 | 가점 | 25 |
| 중복도 패널티 | 감점 | 최대 -15 |
| 자극 제목 패널티 | 감점 | 최대 -10 |
| 본문 빈약 패널티 | 감점 | 최대 -10 |

- 가점 4축 합계 = 100점.
- 패널티는 가점 합계에서 깎는다.
- 최저 0점, 음수는 0으로 절단.

## 5. 신선도 점수 (배점 20)

- 22:00 ~ 05:00 구간 안에서 최신일수록 가점.
- 단순 시간차가 아니라 "구간 내 위치" 로 본다.

### 가점 기준
- 03:00 ~ 05:00 KST 수집분 : **16 ~ 20점**
- 00:00 ~ 03:00 KST 수집분 : **11 ~ 15점**
- 22:00 ~ 24:00 KST 수집분 : **6 ~ 10점**

### 감점 기준
- 22:00 KST 이전 수집분이 섞여 들어왔다면 본 점수식 평가 대상 자체가 아님 → **0점**.
- 너무 최신이지만 근거 강도가 10점 이하라면 신선도에서 **−3** 보정 (최신성만으로 가점받는 것 차단).

### 예시
- 04:42 KST 수집, 1차 출처 + 수치 명확 → 신선도 **18점**
- 23:10 KST 수집, 본문 짧고 출처 약함 → 신선도 **7점**

## 6. 시장 영향도 점수 (배점 30)

- 가격 / 심리 / 자금 흐름 / 정책 / 규제 / 거래소 / 실적 영향 중 어디에 얼마나 직접적인지를 본다.
- 광범위 영향이면 가점, 좁은 단발성이면 감점.

### 가점 기준
- 다중 자산군 동시 영향 또는 시장 전반 정책 / 거시 변수 : **25 ~ 30점**
- 단일 자산군 내 1티어 종목 / 지수 / 주요 자산 영향 : **17 ~ 24점**
- 단일 자산군 내 중·하위권 영향 : **8 ~ 16점**

### 감점 기준
- 영향 시점 불분명 / 발효일 미정 / 추측성 : **0 ~ 7점**

### 예시
- 미 연준 FOMC 결과 + 달러 / 금 / 주식 / 크립토 동시 반응 → 시장 영향 **28점**
- 코스닥 중형주 단일 종목 호재 → 시장 영향 **12점**

## 7. 근거 강도 점수 (배점 25)

- 1차 출처 / 수치 존재 / 본문 길이 / 인용 품질 / 확인 가능한 링크·공시·공식 발표 유무.

### 가점 기준
- 공식 발표·공시·1차 인터뷰 + 수치 명확 + 본문 충분 : **20 ~ 25점**
- 2차 매체 인용 + 수치 명확 : **13 ~ 19점**
- 2차 매체 인용 + 수치 모호 : **6 ~ 12점**

### 감점 기준
- 단일 출처 + 수치 없음 + 본문 짧음 : **0 ~ 5점**

### 예시
- SEC 보도자료 직접 링크 + 수치 4건 인용 + 원문 1500자 → 근거 **23점**
- "관계자에 따르면" 익명 단일 출처, 수치 없음 → 근거 **4점**

## 8. 계정 적합도 점수 (배점 25)

- 금융 / 투자 / 크립토 / 주식 4개 도메인과의 직접성.
- "해석 가능한 소재" 인지 (단순 사실 나열 아님).
- `docs/ACCOUNT_CONSTITUTION.md` 의 주제 정의와 정합되는지.

### 가점 기준
- 4개 도메인 중 1개 이상에 정면 진입 + 해석 축 (왜 지금 / 누구에게 / 자금흐름 / 심리) 중 **2개 이상** 적용 가능 : **20 ~ 25점**
- 정면 진입 + 해석 축 1개 적용 가능 : **12 ~ 19점**
- 도메인 인접 (간접) + 해석 축 1개 적용 가능 : **6 ~ 11점**

### 감점 기준
- 도메인 외 영역 (연예 / 스포츠 / 일반 사회 / 단순 인사) 또는 해석 축 적용 불가 : **0 ~ 5점**

### 예시
- 비트코인 현물 ETF 자금 유입 흐름 분석 가능 소재 → 적합 **22점**
- 거래소 임원 인사 변경 단신 → 적합 **8점**

## 9. 패널티 규칙

### 9.1 중복도 패널티 (최대 -15)
- 같은 사건을 다룬 기사가 CANDIDATE 풀에 여러 건 존재할 때 적용.
- 같은 이슈로 묶인 기사 N건 중 **최고점 1건은 무패널티**, 나머지는 **−15**.
- 묶음 기준 : 핵심 사건 동일 + 핵심 키워드 60% 이상 중첩.
- 결과적으로 같은 이슈는 사실상 1건만 Top5 에 진입 가능.

### 9.2 자극 제목 패널티 (최대 -10)
- 가짜 긴박감 / 단정 표현 / 선동 어휘 사용 시 적용.
- `docs/ACCOUNT_CONSTITUTION.md §4` 금지사항과 정합.
- 감점 신호 (각 −3, 누적, 합산 캡 −10)
  - "충격" / "발칵" / "초비상" 등 과장 부사
  - "확정" / "결정" 인데 본문은 추측
  - 느낌표 2개 이상
  - 익명 부정 인용을 제목 본문화

### 9.3 본문 빈약 패널티 (최대 -10)
- 본문 길이 / 인용 깊이 / 해석 가능성 부족 시 적용.
- 감점 신호
  - 본문 400자 미만 : **−5**
  - 본문 안에 수치 / 인용 / 맥락이 모두 부재 : **−5**
- 두 신호 동시 발생 가능 → 최대 **−10**.

### 9.4 대표 기사 1건 원칙
- 비슷한 기사 과다 유입은 §9.1 중복도 패널티로 자연스럽게 1건만 남는다.
- 동률 발생 시 §10.3 동률 처리 규칙으로 최종 1건 선정.

## 10. Top5 선정 규칙

### 10.1 기본
- 패널티 적용 후 총점 상위 5건을 Top5 로 선정한다.
- 같은 이슈로 묶인 기사 중에는 최고점 1건만 후보에 남긴다.

### 10.2 자산군 균형 규칙
- 같은 자산군 (금융 / 투자 / 크립토 / 주식 중 1개) 만으로 Top5 가 채워지지 않게 한다.
- **동일 자산군 최대 3건까지 허용**.
- 4번째부터는 차순위 후보로 강제 교체.
- **예외** : 시장 영향도 28점 이상인 광범위 영향 건은 자산군 캡 미적용.

### 10.3 동률 처리
- 총점 동률 발생 시 다음 우선순위로 정렬
  1. 근거 강도 점수 높은 쪽
  2. 자극 제목 패널티 적은 쪽
  3. 신선도 점수 높은 쪽
  4. 그래도 같으면 보수적인 쪽 (단정 표현이 더 적은 쪽)

### 10.4 점수 하한선
- 총점 **60점 미만은 Top5 에 올리지 않는다**.
- 60점 이상 후보가 5개 미만이면 Top5 가 부족해도 억지로 채우지 않는다.
- Top5 가 4건 / 3건 / 2건이 되어도 그대로 발송한다.
- 60점 이상 후보가 0건이면 **05:00 브리핑 자체를 생략**한다.

### 10.5 결과 표기
- 텔레그램 카드 형식은 `docs/TELEGRAM_BREAKING_ALERT_TEMPLATE.md` 의 Top5 양식을 따른다.
- 본 문서는 점수 산정과 선정 로직만 책임진다.

## 12. 운영 메모

- 본 문서는 05:00 브리핑 점수 기준선이다.
- `BREAKING_ALERT_FILTER_SPEC.md` 와 충돌하면 **FILTER_SPEC 우선**.
- `TELEGRAM_BREAKING_ALERT_TEMPLATE.md` 와 충돌하면 **TEMPLATE 우선**.
- 본 문서가 책임지는 것은 점수 산정과 5건 선정 로직 뿐이다.
- 이후 구현 / 자동화 / 대시보드 표시 기준은 본 문서를 따른다.
- 점수 가중치는 운영 데이터가 쌓인 후 본 문서를 직접 갱신해 조정한다 (코드 직접 수정 금지).
- 본 문서는 자동화 코드보다 항상 1단계 위에 있어야 한다.
- 새로운 패널티 / 새로운 가점 축이 필요하면 별 P0 분기로 본 문서를 먼저 갱신한 후에 코드 반영.
- 채점은 운영자가 손으로도 가능해야 한다. 정밀한 척하는 가짜 소수점 / 가짜 정밀도 금지.
