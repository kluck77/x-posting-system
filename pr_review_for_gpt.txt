### [A] 5-Criteria 품질 프레임워크 통합

목표: "번역이 아닌 해석" 계정 차별화 강화.
5개 기준: expertise(해석력) / marketability(글로벌 관련성) /
           consistency(브랜드 일관성) / follower_quality(독자층) / repeat_consumption(재방문력)

#### app/services/quality_scorer.py (신규, 434줄)

score_draft() — 초안 채점 (0-100점):
  +20 훅에 숫자/지표 포함
  +20 훅이 "South Korea"로 시작하지 않음
  +15 CTA 포함 (Follow/Bookmark/Thread)
  +15 본문 270자 이하
  +10 "you" 직접 호칭
  +10 구체적 국가/기관명
  +10 커뮤니티 반응 표현
  -15 금지어 (however/furthermore/moreover 등)
  임계값: 60점 미만 → 재생성

score_5criteria() — 5기준 채점 (각 20점, 합계 100점):
  점수 >= 70: pass / 50-69: warn / < 50: reject+재생성

### content_fetcher.py — 3단계 fallback

```python
async def fetch_url_content(url: str) -> dict:
    result = await _fetch_direct(url)        # Strategy 1: Chrome UA
    if result: return result
    result = await _fetch_jina(url)          # Strategy 2: r.jina.ai
    if result: return result
    result = await _fetch_google_cache(url)  # Strategy 3: Google Cache
    if result: return result
    return {"source": "failed", "error": "모든 수집 전략 실패"}
```
